Card Duel 教学素材包

适用参考版本：Unity 6000.6.0f1。
导入：在教学项目选择 Assets > Import Package > Custom Package，选择 CardDuelLearningAssets.unitypackage，再点击 Import。

目录
- Art/Cards：52 张普通扑克牌、1 张通用 Joker 图、15 张牌背。图片为 140x190，Image 请启用 Preserve Aspect。
- Art/UI：按钮、输入框底图、滑块、选框、箭头。矩形按钮及输入框已设置 Sprite Border，可在 UI Image 选择 Sliced。
- Art/Icons：设置、帮助、退出、音量、加减、回手等白色图标，可用 Image Color 调色。
- Art/Hearts：完整、半颗、空心生命图标。
- Resources/Fonts：Noto Sans CJK SC Regular。
- Resources/Audio：原 Demo 的 9 种音效与用户提供的 BGM。
- Licenses：原始授权、来源链接和下载文件校验值。

范围与使用
- 所有图片已按 Sprite (2D and UI)、Single、Bilinear、无 Mip Maps 导入；不依赖 SVG 插件或自定义脚本。
- 不包含任何游戏逻辑、场景、Prefab、包依赖或项目配置。界面由你在教学项目中搭建。
- 原 Demo 的绿色桌布可直接用 Canvas 下的 Image，通过 Inspector 的 Color 设置为 #2B654D，无需编程画图；按钮也可调色。
- 这个非像素卡牌来源只有一张 Joker 基图。大小王可以共用该 Sprite，再用两个 UI 文本标注；素材包没有声称存在两张不同 Joker 原画。
- 本包提供相近风格的公开素材，不是原 Demo 的像素级复刻；牌效标记由图标与文本组合。
