# Big Old Guy v0.1.0

最初の公開プレイアブル版です。 / 首个公开可玩的版本。

## ダウンロード / 下载

`BigOldGuy-v0.1.0-Windows-x64.zip` を解凍し、`BigOldGuy.exe` を実行してください。DataフォルダーとDLLを移動・削除しないでください。

解压 Windows x64 压缩包后运行 `BigOldGuy.exe`，保留同目录的 Data 文件夹和 DLL，无需安装 Unity。

## 内容

- AIとの1人対戦。54枚のトランプ、HP、11種類の組み合わせ、段階ごとのカード効果。
- 日本語・中国語・英語、BGM・効果音、音量とAI設定の保存。
- プレイヤー画面には乱数シードの表示・入力はありません。

- 单人对战 AI，54 张扑克牌、生命值、11 种牌型和分阶段牌效。
- 中日英界面、BGM 与音效、音量及 AI 设置保存。
- 玩家设置不显示或编辑随机种子。

## 制限 / 限制

Windows 64 bit 用のデモです。オンライン対戦はなく、直前の手の画像は先頭8枚まで表示します。複数PCでの互換性は未検証です。

这是 Windows 64 位 Demo，不支持联网；上一手图片最多显示前 8 张，完整记录可查日志。尚未验证多台电脑的兼容性。

詳しい操作と制作過程は README を参照してください。操作与开发说明请参阅 README。素材许可文件随压缩包附带。

## 検証 / 验证

Unity 6000.6.0f1 の Windows x64 ビルドに成功。42グループのルール検証と5つの自動対戦が完了しました。Windows実行ファイルで、じゃんけん、ドロー、選択、提出、AIの進行、日本語設定、プロセス再起動後の言語設定の保持を確認しています。

Unity Windows x64 构建成功；42 组规则检查、5 局自动对战通过。独立程序实测了猜拳、抽牌、选牌、出牌、AI 推进、日语设置，以及退出后在新进程中读回语言设置。

ビルド結果はエラー0、警告509。警告には既存の Sentis パッケージのシェーダー警告が含まれます。実際のスピーカー出力と他PCでの動作は未検証です。

构建结果为 0 错误、509 警告，其中包含已有 Sentis 包的着色器警告。未验证真实扬声器输出及其他电脑的运行情况。
